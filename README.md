# Maze Game
* this is a simple maze game by [Python](https://www.python.org)
* it sets the start at the left up corner
* it used [DFS](https://www.geeksforgeeks.org/dsa/depth-first-search-or-dfs-for-a-graph/) to generate the maze
* the exit will be a random place, or you can set the seed to control the map
* while you play, you should light the way by yourself :)

HOW TO PLAY
: Python: >= 3.12
: install: [pygame](https://github.com/pygame/pygame), [colorama](https://github.com/tartley/colorama)

* move keys: `W` `A` `S` `D`
* WIN: reach the exit

Have a good play! :D
