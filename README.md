## Maze Game
* this is a simple maze game by python
* it sets the start at the right up corner
* it used DFS to generate the maze
* the exit will be a random place, or you can set the seed to control the map
* while you play, you should light the way by yourself :)

HOW TO PLAY
: Python: >= 3.12
: install:  pygame, colorama
: run main.py, then you can see the tips

* move keys: ``W`` ``A`` ``S`` ``D``
* WIN: reach the exit

Have a good play! :D
